# WeryAI API Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A cross-platform skill that wraps the [Wery AI API](https://docs.weryai.com) for use in **OpenClaw**, **Cursor**, **Claude Code**, and **Codex**. This skill enables AI coding assistants to interact with Wery AI’s intelligent API services directly from your development workflow.

---

## ✨ Features

- **Unified Interface** – One skill works across OpenClaw, Cursor, Claude Code, and Codex.
- **Full API Coverage** – Exposes all endpoints documented at [docs.weryai.com](https://docs.weryai.com).
- **Seamless Authentication** – API key management through environment variables or skill configuration.
- **Streaming Support** – Handles streaming responses where applicable.
- **Error Handling** – Graceful fallbacks and clear error messages.
